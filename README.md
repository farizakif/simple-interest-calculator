# Simple Interest Calculator

## Project Description

The Simple Interest Calculator is a simple Bash-based application that calculates the simple interest earned on a principal amount based on the rate of interest and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:
- Principal: Initial amount of money.
- Rate: Annual rate of interest.
- Time: Investment period in years.

## Features

- Accepts principal amount from the user.
- Accepts annual rate of interest.
- Accepts time period in years.
- Calculates and displays the simple interest.

## Technology Used

- Bash Scripting
- Linux Command Line

## Usage

Run the script using:

```bash
bash simple-interest.sh
```

Enter the principal amount, rate of interest, and time period when prompted.

## Project Objective

This project demonstrates basic Bash scripting, user input handling, arithmetic operations, and command-line application development.
